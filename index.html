أين يعمل الذكاء الاصطناعي؟

أمان: لا تحفظ مفاتيح API داخل هذا التطبيق. يفضل خادمك الشخصي مع HTTPS؛ Safari قد يمنع خادم HTTP عند فتح الموقع بـ HTTPS. يحتاج الخادم إلى السماح لاتصالات المتصفح (CORS).
